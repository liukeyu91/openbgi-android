# Android 概述

## 平台与结构

- Android 9 及以上，ARM64。
- Java Activity、SurfaceView 和 JNI 管理界面及原生引擎。
- 每次游戏会话在独立引擎进程中运行。
- EGL / GLES2 显示画面，AAudio 输出音频。

## 游戏与存储

- 全功能包在授权后可原地读取已解压的游戏目录。存档与展开的汉化资源写入应用存储。
- 也可添加光盘镜像或游戏压缩包：直接在存储中选取 ISO（ISO9660 或 UDF）或 ZIP 文件，文件留在原位，不复制、不解包。
- SAF 包通过系统选择器复制导入游戏，授权限于所选目录。
- 也可通过系统目录选择器复制导入，保留文件名大小写及子目录；现有应用内副本继续可用。
- 每个游戏位于 `files/games/<id>/`，配置保存在 `.openbgi/` 中。
- 游戏存档、编码、引擎配置和操作设置按游戏独立保存。
- 游戏菜单提供存档 ZIP 导出与导入，包含存档和全局进度。导入支持应用生成的备份包，校验后确认覆盖同名文件，保留备份以外的文件；中断后会在启动游戏前恢复未完成的操作。请先存档并退出游戏，并使用同版本游戏的备份。

## 光盘镜像与游戏压缩包

- 两者使用同一套“容器”模型：条目只记录来源文件（`.openbgi/source.txt`）与摘要（`.openbgi/source.properties`，含类型、根位置、启动档案与档案语言）；游戏库与启动检查读摘要，不重复解析来源。早期版本写入的 `source-image.txt` 与 `image.properties` 仍可读取。
- 添加时确认根目录存在启动档案（`system.arc`、`ipl._bp` 或本地化档案对），并找出最浅的一层作为游戏根，因此带一层外层目录的镜像或压缩包也能入库。
- 启动时原生层挂载来源，文件服务按索引读取，路径解析、档案语言优先级、补丁层与私有数据层均与目录游戏一致；镜像条目支持 4 GiB 以上的范围。
- ZIP 使用同一索引接口：Stored 条目直接定位读取，Deflate 条目在首次打开时解压并校验 CRC-32，之后按字节范围读取。ZIP64 的结束记录与逐条目扩展字段均支持；加密、以及使用其他压缩方式的条目会被列出但无法读取。压缩包内未列出的父目录会按文件路径补齐，目录属性与枚举仍可用。
- 解压后的单个条目上限为 256 MiB，避免低配设备因超大条目耗尽内存；超过上限的条目按缺失处理。
- 来源为只读：存档、设置与展开资源写入 `files/games/<id>/.openbgi/data`。来源自带的存档在添加时复制到该目录并列入 `original-saves.txt`，之后与其他游戏一样导出、导入。
- 汉化资源不能就地展开，镜像与压缩包条目请使用覆盖包（ZIP）；覆盖包优先于来源内容。
- 编码按档案语言与脚本文字抽样决定，抽样经同一条目读取路径（Deflate 条目按需解压）。来源文件被替换或移走后，条目保留但无法启动，需要重新添加。

## 编码与配置

- 支持 SJIS、GBK、UTF-8，以及脚本文字抽样自动检测。
- 检测不明确时，通过编码预览和手动选择确定设置。
- 引擎配置可自动识别，也可通过 `games.json` 或设置页指定。
- 容器游戏的档案语言来自游戏根目录的档案名，抽样与预览直接读取镜像或压缩包条目。
- 更改设置后，重新启动游戏生效。

## 输入与生命周期

- 支持点击、长按、双指点击、滚轮手势和拖拽。
- 提供可配置的屏幕快捷键、键盘和基本手柄映射。
- 快进按钮默认模拟持续按住 Ctrl，点按切换；点击画面、收起快捷键或离开游戏时停止。可按游戏修改映射。
- 文字输入使用 Android 输入控件及输入法。
- 切到后台或失去音频焦点时暂停游戏；恢复方式取决于中断类型。
- 运行日志可从关于页导出。

## 程序检查

- 导入完成后检查 `._bp` 程序，列出缺失或不支持的指令及其位置。
- 已导入的游戏可从卡片菜单选择“兼容性检查”。
- 检查使用所选或自动识别的引擎配置，结果按游戏保存。
- 容器游戏的程序同样来自镜像或压缩包条目（根目录或 `system.arc` 内）；无法识别版本或完整读取资源时，会标明检查未完成或不完整。

## 兼容性

常规本地影片通过内置 FFmpeg 播放，支持常见 MPEG、WMV、AVI、MP4 等容器及已启用的音视频编码；不需要另装 FFmpeg 程序。声音接入游戏混音器，切后台暂停，点击影片或按 Esc / Enter 可跳过。解码失败会记录日志并提示跳过。
BF_Movie 帧序列仍使用引擎自身解码器，流式 BF_Movie 不在这次支持范围内。受限于已编入的编码器，支持某个扩展名不代表支持其中的所有编码；不播放网络影片。
不同作品及汉化补丁需要分别确认兼容性。混合编码及部分显示效果仍有限制。
静态指令检查不覆盖动态加载和其他脚本格式，也不代表完整流程兼容。
封装在 Windows EXE 内的汉化覆盖资源需先展开到游戏目录；应用不执行 Windows EXE。
