# Android 概述

## 平台与结构

- Android 9 及以上，ARM64。
- Java Activity、SurfaceView 和 JNI 管理界面及原生引擎。
- 每次游戏会话在独立引擎进程中运行。
- EGL / GLES2 显示画面，AAudio 输出音频。

## 游戏与存储

- 通过系统目录选择器导入已解压的完整游戏目录。
- 导入保留文件名大小写及子目录，并复制到应用存储。
- 每个游戏位于 `files/games/<id>/`，配置保存在 `.openbgi/` 中。
- 游戏存档、编码、引擎配置和操作设置按游戏独立保存。
- 游戏菜单提供存档 ZIP 导出与导入，包含存档和全局进度。导入支持应用生成的备份包，校验后确认覆盖同名文件，保留备份以外的文件；中断后会在启动游戏前恢复未完成的操作。请先存档并退出游戏，并使用同版本游戏的备份。

## 编码与配置

- 支持 SJIS、GBK、UTF-8，以及脚本文字抽样自动检测。
- 检测不明确时，通过编码预览和手动选择确定设置。
- 引擎配置可自动识别，也可通过 `games.json` 或设置页指定。
- 更改设置后，重新启动游戏生效。

## 输入与生命周期

- 支持点击、长按、双指点击、滚轮手势和拖拽。
- 提供可配置的屏幕快捷键、键盘和基本手柄映射。
- 快进按钮默认模拟持续按住 Ctrl，点按切换；点击画面、收起快捷键或离开游戏时停止。可按游戏修改映射。
- 文字输入使用 Android 输入控件及输入法。
- 切到后台或失去音频焦点时暂停游戏；恢复方式取决于中断类型。
- 运行日志可从关于页导出。

## 程序检查

- 导入完成后检查 `._bp` 程序，列出缺失或不支持的指令及其位置。
- 已导入的游戏可从卡片菜单选择“兼容性检查”。
- 检查使用所选或自动识别的引擎配置，结果按游戏保存。
- 无法识别版本或完整读取资源时，会标明检查未完成或不完整。

## 兼容性

常规本地影片通过内置 FFmpeg 播放，支持常见 MPEG、WMV、AVI、MP4 等容器及已启用的音视频编码；不需要另装 FFmpeg 程序。声音接入游戏混音器，切后台暂停，点击影片或按 Esc / Enter 可跳过。解码失败会记录日志并提示跳过。
BF_Movie 帧序列仍使用引擎自身解码器，流式 BF_Movie 不在这次支持范围内。受限于已编入的编码器，支持某个扩展名不代表支持其中的所有编码；不播放网络影片。
不同作品及汉化补丁需要分别确认兼容性。混合编码及部分显示效果仍有限制。
静态指令检查不覆盖动态加载和其他脚本格式，也不代表完整流程兼容。
封装在 Windows EXE 内的汉化覆盖资源需先展开到游戏目录；应用不执行 Windows EXE。
