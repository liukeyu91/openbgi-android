# Android 0.10.5-preview：导入及启动时检测文字编码

2026-11-14，versionCode 18，ARM64 / Android 9+。

## 问题与修复

此前新导入目录直接写入 SJIS，抽样检测只由编码预览调用；卡片上的引擎版本自动识别与文字编码是两个独立功能。
现在复制完成后，后台抽样读取场景文字，检测 SJIS、GBK 或 UTF-8，保存识别结果和自动模式。
原生引擎继续读取明确的三选一编码，未增加新的引擎参数。

设置页新增自动识别选项；游戏卡片区分待检测、已确定和未确定。
无可用样本、判断不明确或混合编码时，不以隐含的 SJIS 运行，而是提示预览并手动选择。
检测结果持久化，正常启动和对白推进不重复抽样。

旧版仅在 encoding.txt 留下 SJIS、未显式保存编码的目录，会在首次启动时检测。
settings.ini 中已有的显式编码，包括 SJIS，以及旧版 GBK/UTF-8 配置都会保留。
如需重新检测已手动设置的游戏，在游戏设置中选择自动识别、保存，再启动游戏。
其他设置及原有存档保留；检测不写入游戏档案、脚本或存档。

## 验证范围

- 39 项原抽样检查、35 项自动编码集成检查、48 项输入/设置检查通过。
- 270 组 Java 与原生缩放计算对照通过。
- Fureraba 汉化目录：72 条样本，GBK 58 票、SJIS 3 票，自动保存 GBK。
- Kanojo Step 已展开汉化资源：72 条样本，GBK 62 票、SJIS 0 票，自动保存 GBK。
- Kanojo Step 未展开汉化的原始目录：72 条样本，SJIS 51 票、GBK 10 票，保存 SJIS；该目录的 ARC 仍是日文脚本。
- 真实资源验证只读原目录，配置写入独立临时目录；测试结束后清理临时配置。
- 两种 APK 的 Java 编译、签名与 16 KiB 对齐、原生库一致性、源码归档及累计补丁检查通过。

主机检查不代替手机实际导入和启动。本版 ADB 未连接，未安装到真机；原生库与 0.10.4 相同。
自动检测沿用有限抽样和文本评分，无法保证所有游戏都准确识别，混合编码也未因此得到修复。
汉化文件若封装在 Windows EXE 内，须先展开覆盖资源；编码设置不会执行或提取 EXE。

提供主应用 org.openbgi.port 和独立 UI Preview org.openbgi.uipreview 原位升级包，两者数据独立。
APK 与发布源码不含游戏、存档、密钥或本地验证资源。
