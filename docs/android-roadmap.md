当前优先级：修复新导入游戏的编码初始化，接入自动检测并保留手动设置；其他未解决问题继续保留。

另报告《与她》有立绘时推进约延迟 0.3 秒，CG/无立绘正常；先离线排查，随后授权操作手机验证。
0.10.1-preview 已阻止零字节启动文件被当成游戏，隐藏之前留下的两个空演示条目，不删除任何数据。
优化通用透明合成、平滑变换和 Android 等尺寸画布拷贝；像素/导入回归通过。
真机验证：空演示条目已隐藏，真实导入的 Fureraba 和 Kanojo Step 可启动并读取后者快速存档。
同一存档三句对照未见实质改善：0.10.0 约 86/1113/87 ms，0.10.1 约 103/1112/104 ms。
这些是录屏下从系统派发抬手到下一句首次出现的近似时间，包含脚本演出；不能把中间约 1 秒全算作引擎耗时。
性能问题尚未通过验收；采样提示继续检查图片解码、RGB 混合与资源查找，不能只优化平滑变换。
同时交付 org.openbgi.uipreview 原位升级包，保留用户在预览应用里自行导入的游戏和存档。

0.10.2-preview 进一步真机分段计时：一次立绘变化把同一组 7 张图片解码两遍，合计约 404 ms，
实际大块数据读取不到 1 ms，另有约 58 ms 打开/路径处理及合成开销。
已添加 Android 默认 64 MiB / 16 项、按完整压缩内容匹配的 CBG LRU 解码缓存，后台/退出释放。
同片段解码 14 → 7 次、404 → 203 ms；无钩子安装包整体推进约 1.112 → 0.908 秒。
这修复了重复解码，不能宣称所有有立绘场景延迟均已消除；首次解码/合成和既有局部黑块仍待处理。

0.10.3-preview：加入 CBG v1 前缀 Huffman / 四通道预测还原，
ARM64 NEON 透明合成/交叉淡化，以及目录名称快照缓存；图片缓存仍为 64 MiB。
同一片段无钩子 APK 实测 908 → 669 ms，缩短约 26%；首次解码阶段约 203 → 106 ms，资源打开/路径处理约 54 → 3.4 ms。
主机 6 组相关回归和真实 ARM64 解码/合成/路径检查通过；14 次真实图层与旧解码器逐字节一致。
两个应用原位升级为 code 16，11 个存档校验一致；仍不代表局部黑块和所有场景停顿已修好。

0.10.4-preview：更新游戏库、使用说明、关于、设置和编码预览的文字。
关于页从已安装包读取版本；兼容性说明区分部分验证和完整流程。
仅更新 Java 界面和版本元数据，原生引擎与 0.10.3 相同。当前 ADB 未连接，尚未安装或检查本版真机布局。

0.10.5-preview：导入和首次启动接入脚本文字抽样检测，新增自动编码模式及检测状态持久化。
旧版仅有 encoding.txt=sjis 的导入在首次启动重测；settings.ini 中的显式编码及旧版 GBK/UTF-8 配置保留。
无样本、歧义或混合编码不再使用隐含 SJIS 启动，而是提示预览并选择编码。
39 项抽样、35 项自动编码集成、48 项输入设置及 270 组缩放对照通过。
Fureraba 汉化资源、已展开的 Kanojo Step 汉化资源均检测 GBK；未展开汉化的原始 Kanojo Step ARC 检测 SJIS。
本版无 ADB，未进行手机安装与真实导入/启动流程检查；不代表所有游戏都可可靠识别。

目标是通用的 Android BGI/Ethornell 引擎产品，依次完成 P0、P1、P2。
“第二部游戏跑起来”只代表 P0 里程碑，不代表整体工程完成。
公共发布只包含引擎、自有代码和依法可分发的依赖；游戏由玩家自备。

## 架构约束

- P1 先从 NativeActivity 迁移到 Java/Kotlin Activity + SurfaceView + JNI。
  NativeActivity 只保留为当前 0.4.1 测试基线，不继续在它上面堆 IME、对话框或产品功能。
- 每游戏独立编码配置；增加抽样探测和首句预览，允许用户确认/覆盖。
- 兼容性以实测证据为准，识别成功、单元测试和进入标题都不能代替全程验证。
- 保留上游历史，方便同步；引擎修改和本地游戏资源准备分开记录。
