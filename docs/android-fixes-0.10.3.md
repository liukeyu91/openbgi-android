# Android 0.10.3-preview：解码、NEON 合成与资源查找

2026-11-13，versionCode 16，ARM64 / Android 9+。

继续优化用户报告的《与她＊心渐近》立绘对白停顿。相同快速存档、相同三次触摸，无计时钩子 APK 的一次对照中，
立绘切换从 0.10.2 的约 908 ms 降到约 669 ms，本轮缩短约 26%；0.10.1 的同片段约为 1112 ms。
普通换句的两次结果约 85/69 ms。测量包含游戏演出和录屏开销，不能视为所有游戏的平均延迟。

## 实际修改

- CBG v1 Huffman 解码增加 8 位前缀查表，长码保留逐位路径；只读取当前字节，不为查表预读压缩流末端以外的数据。
- 32 位图片的预测还原一次计算四个通道；8/16/24 位路径拆分首行/首列，去掉逐通道边界分支。保持原逐字节取整与模 256 加法。
- ARM64 使用 NEON 一次处理 8 个像素的 ARGB→RGB 透明合成和交叉淡化，保留 BGI 的 7 位权重、各次取整及目的高字节规则。透明块快速跳过，尾部走标量路径；部分重叠的源/目标退回原前向写入顺序。
- 普通 RGB 混合及交叉淡化缓存生成改为打包通道计算；非标准淡化比例保留原标量处理。
- 文件名大小写查找保存最多 4 个目录快照，每个目录名称最多 256 KiB。每次用 inode、设备号、大小及纳秒修改/变更时间验证；近期变化的目录直接扫描，构建前后再次核对属性，目录过大或分配失败时直接回退。缓存受互斥锁保护。

CBG 图片缓存继续使用 0.10.2 的 64 MiB / 16 项限制，后台及引擎退出时清空。
本轮没有提高图片缓存容量，没有调整游戏图片、分辨率、编码或脚本演出时长。

## 验证及交付

Linux 主机相关 6 组回归、真实 ARM64 设备上的解码/合成/路径回归通过。
真实游戏的 14 次图片解码与冻结的 0.10.2 解码器逐字节对照全部一致。
主应用和 UI Preview 均已原位升级到 0.10.3；现有 11 个 .sud 的 SHA-256 与本轮测试前一致。
详情见 [真机验证记录](android-device-validation-0.10.3.md)。

仍有首次 CBG v2 解码、ARGB 内部图层合成等开销；既有局部黑块和其他兼容性问题继续保留在路线图中。
这次改善覆盖了选定片段，不代表所有立绘场景都已消除停顿。

交付标准包 org.openbgi.port 和独立预览包 org.openbgi.uipreview，覆盖安装保留各自数据；包中仅有引擎与可分发依赖。
源码 ZIP 与累计补丁同时更新，不包含游戏、存档、签名密钥、临时计时钩子或参考解码器。
本轮没有向 GitHub 推送。
