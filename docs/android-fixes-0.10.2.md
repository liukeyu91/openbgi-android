# Android 0.10.2-preview：立绘重复解码

2026-11-13，versionCode 15，ARM64 / Android 9+。

用户怀疑《与她＊心渐近》的立绘渲染或读取导致对白推进停顿。
本轮真机分段计时确认，一次立绘变化重复加载同一组 7 张 CBG 图片，共解码 14 次，解码合计约 404 ms。
该次实际数据读取约 0.6 ms，另有打开文件/路径查找及图层合成开销；这些数据不能把停顿归因于磁盘速度。
上游重写版的 Loader_QueueFile 同步调用 LoadFile，也没有经过 BmpOp_LoadFile 的脚本缓存路径。

新增 CBG 解码结果缓存，覆盖这条加载路径及解码后的大小/范围查询。
Android 默认最多 64 MiB、16 项，使用 LRU 淘汰，预算同时计入压缩数据、解码结果和条目本身。
每次仍读取当前资源，完整比较压缩字节后才复用结果；同名文件被替换或档案重载不会按旧文件名误命中。
只缓存解码成功的图像，失败不缓存；缓存分配失败时正常返回已解码图像。
缓存保存独立副本，后续图层改动不影响缓存；24 位加载器原有的未写尾部保持原行为。
后台暂停与引擎结束时释放缓存，其他平台默认关闭。缓存当前由引擎线程使用，未来加入真正异步加载时需要同步保护。

小米 8 同一快速存档复测：

| 指标 | 0.10.1 | 0.10.2 |
| --- | ---: | ---: |
| 一次立绘切换的实际解码次数 | 14 | 7 |
| 解码总耗时，临时分段计时版 | 404 ms | 203 ms |
| 抬手至下一句文字可见，无计时钩子版本 | 1112 ms | 908 ms |

该片段的整体等待缩短约 200 ms，约 18%；剩余时间仍包含首次解码、图层合成与脚本演出。
这不是所有有立绘场景的平均值，不宣称用户反馈的所有延迟都已消除。
没有降低分辨率、改变解码算法、缩短脚本等待或修改游戏文件。
逐项验证、记录方法及仍存在的显示问题见 [真机记录](android-device-validation-0.10.2.md)。
