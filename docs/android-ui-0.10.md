# Android 0.10.0-preview — 新游戏库 UI

日期：2026-11-13。ARM64 / Android 9+，versionCode 13。

## 本轮范围

本版更新启动器和设置界面；游戏内游玩、画面和存读档仍需独立验证。
本轮没有继续扩展玩家改名功能，也没有将 UI 验证记作游戏兼容性通过。

- 暖白背景、深绿色强调色、统一矢量图标与应用图标。
- 封面卡片游戏库；点封面或“开始游戏”直接启动，更多菜单管理作品。
- 名称搜索、最近打开/名称排序、重命名、自选图片封面。
- 无自选图片时使用代码绘制的抽象书封，不随包提供游戏图片。
- 竖屏底部导航、横屏侧栏；指南和关于页独立，日志导出放在关于页。
- 设置按文字与兼容、显示与操作、按键映射分组；取消不落盘，保存后下次启动生效。
- 游戏内快捷键改为紧凑的半透明折叠浮层，保留原快捷键映射。
- 导入保持完整目录复制及原大小写，导入过程中显示状态。

## 数据与封面

游戏和存档继续位于原 `files/games/<id>/`，没有移动游戏资源。
名称存于 `.openbgi/name.txt`，打开时间存于 `.openbgi/last-played.txt`。
自选封面读取上限 20 MB，缩小后重新编码为 `.openbgi/cover.jpg`；取消选择不会替换封面。
显示时按封面区域居中裁剪，缩略图使用有上限的内存缓存。应用不访问网络获取封面。

## 验证范围

Java 编译、Android 资源编译、DEX、APK 签名和 16 KB 对齐通过。
沿用已有每游戏配置数据结构，设置/输入回归及 270 组原生/Java 坐标向量通过。
主 APK 不带 UI 演示数据、测试入口、游戏资源或个人存档。

真机 UI 检查使用独立包 `org.openbgi.uipreview`，其目录只有空识别文件与演示名称，
不共享 `org.openbgi.port` 的资源或存档，不启动主应用的游戏剧情。
小米 8 / Android 10 已实际打开横竖屏游戏库、指南、关于和设置页；
搜索无结果状态可见；设置选择 UTF-8 后取消，演示目录仍保留 GBK。
横屏缩小封面与卡片间距，竖屏导航标签居中。主游戏进程在 UI 检查前后保持同一 PID；
临时旋转检查结束后恢复原来的横屏锁定。未测试相册选择、真实目录导入或删除已有作品。
用户操作手机期间不覆盖主应用；正式 UI APK 由用户自行覆盖安装。
实际游戏、不同字体缩放、更多设备以及相册来源仍需用户反馈，不据构建通过宣称全部验证完成。

## 输入状态修复的真实边界

此前只依据 Android 键盘可见高度更新 `B0 23`。Kanojo Step 在创建编辑控件后立即查询此值，
键盘动画尚未完成就读到关闭，脚本随即隐藏控件。现在 `OS_EditFocus` 先建立逻辑编辑会话，
Java 完成、取消或隐藏控件时结束会话；临时后台暂停仅隐藏键盘。
曾在实际改姓入口输入 AB，返回姓名界面显示 AB，未确认整个姓名表单，也未写入游戏存档。
该观察来自本轮开发构建，最终已清除诊断对象并重编译，未重新开展游戏流程测试。
仍观察到局部黑块；玩家输入是否进入实际对白未验证。Fureraba 新版备注流程也未验证。
这些限制保留，不将本版称为输入/渲染问题全部修复。
