# Android 0.10.4-preview：界面文字更新

2026-11-13，versionCode 17，ARM64 / Android 9+。

游戏库显示游戏数量、搜索结果和导入状态。空列表说明所需目录和复制行为，默认封面标注其用途。
使用说明描述完整目录导入、三种文字编码和触摸输入的映射。
设置页简化编码名称，说明按键效果取决于游戏自身的设置，以及保存后需重启游戏。
编码预览和初始文字编码菜单使用一致的名称，并说明选择后的生效范围。

关于页从安装包读取版本，说明应用提供引擎、需要自行导入游戏；兼容性记录限定为两部游戏的启动、部分对白和读档。
日志导出入口与引擎启动错误提示保持对应。

此次仅更新 Java 界面、版本元数据和文档。原生引擎沿用 0.10.3，不更改游戏资源或脚本。
现有显示、混合编码、性能及完整流程兼容性问题继续保留在路线图中。

交付主应用 org.openbgi.port 和独立预览包 org.openbgi.uipreview，均沿用各自已有签名。
覆盖安装可保留同一包内的数据；两种包的数据彼此独立。
构建检查包括 Java 编译、APK 签名与 16 KiB 对齐、两个包的原生引擎及 Java 类一致性、源码归档及累计补丁检查。
本版 ADB 未连接，尚未进行真机安装、布局和交互检查；0.10.3 的真机记录仍单独保留。

源码与 APK 不包含游戏、存档或签名密钥。本版未推送到 GitHub。
